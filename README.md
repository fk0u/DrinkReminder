# DrinkReminder

A simple application to remind you to stay hydrated throughout the day.

## Overview

DrinkReminder is a helpful utility that sends notifications at regular intervals to remind you to drink water. Staying hydrated is essential for maintaining good health and productivity.

## Features

- Customizable reminder intervals
- Water intake tracking
- Daily hydration goals
- Simple and intuitive interface

## Installation

```bash
# Clone the repository
git clone https://github.com/yourusername/DrinkReminder.git

# Navigate to the project directory
cd DrinkReminder

# Install dependencies
npm install
```

## Usage

```bash
npm start
```

## Configuration

You can customize your reminder settings in the `config.json` file:

```json
{
    "intervalMinutes": 30,
    "dailyGoalOz": 64,
    "startTime": "08:00",
    "endTime": "22:00"
}
```
